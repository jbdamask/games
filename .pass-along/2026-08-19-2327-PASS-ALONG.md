## Traps

- **Map URL via WebFetch = HTTP 500.** Use `curl -L -A "Mozilla/5.0" -o montauk-map.jpg <url>`.
- **No system Pillow.** `python3 -m pip install pillow` fails (PEP 668). A disposable venv was `/tmp/venv` with Pillow for overlay/grid scripts; it may already be gone.
- **JS inch marks.** `inch + '" bass"` without a closing single quote is a SyntaxError. `node --check` on extracted script caught it; a browser would have been a blank page.
- **Canvas + DPR.** After `vctx.setTransform(dpr,…)`, fill using `view.clientWidth/Height` (see `viewCss()`), not `view.width/height`.
- **Wind shift.** `Math.floor(elapsedMin) % 75 === 0` is true for an entire game minute at t=0 and every 75 min. Use a slot counter (`G.weatherSlot`).
- **Image tools do not show the map.** Spot placement from captions will drift. Draw a debug overlay in-page (`SPOTS` dots) rather than trusting a description.
- **`/pass-along` before the skill is attached** does nothing useful. Need `/home/rocky/.cursor/skills/pass-along/SKILL.md`.
