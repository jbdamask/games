## Traps

- **`/games/` on `jbdamask.github.io` overwrites the hub.** Custom domain `johndamask.com/games/` is `jbdamask/games`, not the blog repo. The github-pages-deploy skill wanted a brand-new `surf-rats` repo; that was the wrong target.
- **Map URL via WebFetch = HTTP 500.** `curl -L -A "Mozilla/5.0" -o montauk-map.jpg <url>`.
- **Image tools do not show the map.** Spot placement from captions will drift. Draw a debug overlay in-page (`SPOTS` dots).
- **JS inch marks.** `inch + '" bass'` without a closing single quote is a SyntaxError. `node --check` on extracted script caught it.
- **Canvas + DPR.** After `vctx.setTransform(dpr,…)`, fill using `view.clientWidth/Height` (`viewCss()`), not `view.width/height`.
- **Wind shift.** `Math.floor(elapsedMin) % 75 === 0` is true for an entire game minute. Use a slot counter (`G.weatherSlot`).
- **`gather.sh` uses cwd as repo root.** A leftover `/tmp/games` cwd makes the workspace look like that clone. Cursor workspace is `/home/rocky`.
- **`/pass-along` before the skill is attached** does nothing useful.
